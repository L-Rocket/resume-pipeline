# Repository instructions

- Never commit personal resume content, generated documents, transcripts, application records, photographs, browser captures, credentials, or local absolute paths.
- Treat the files under `latex/` as the source of truth for application-ready resumes.
- Keep `reference/resume_master_en.md` and `reference/resume_master_cn.md` structurally synchronized.
- Run `make test`, `make privacy`, and `make verify` after relevant changes.
- Do not commit changes without the repository owner's permission.
